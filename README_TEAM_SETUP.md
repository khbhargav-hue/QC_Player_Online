# QC Player Online — Free Team Setup & Update Guide

This guide allows your **10 team members** to run **QC Player Online** for **$0.00 (100% Free)** with:
- **Direct in-page Google Docs editing** (`/edit` mode right inside the player window).
- **1-Click automated updates** without re-downloading zip files manually.

---

## 🛠️ Initial One-Time Setup for Team Members

### Step 1: Place Folder in Shared Drive
Place the `QC_Player_Online_Extension` folder in a shared Google Drive, OneDrive, or local network folder accessible by your team.

### Step 2: Load Extension in Chrome (One-Time)
1. Open Google Chrome and go to `chrome://extensions/`.
2. Turn ON **Developer mode** (toggle in top-right corner).
3. Click **Load unpacked** (top-left corner).
4. Select the `qc_web_ext` folder located inside `%LOCALAPPDATA%\QC_Player_Online_Extension\qc_web_ext` (or the shared folder).

---

## 🔄 How Team Members Get 1-Click Updates ($0)

Whenever you update code in the master shared folder:
1. Team members simply double-click **`Update_QC_Player.bat`**.
2. The script instantly syncs the newest code to their computer in 1 second and launches Chrome!
3. **No zip file downloads, no manual re-installations, 100% Free!**
